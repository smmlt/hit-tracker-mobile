# Hit Tracker Mobile

Expo / React Native client for Hit Tracker on Android, iOS, and the web.

## Android download

[Download the latest universal APK](https://github.com/smmlt/hit-tracker-mobile/releases/latest/download/HitTracker-Android-universal.apk) for Android 7.0 or newer. The APK includes `armeabi-v7a`, `arm64-v8a`, `x86`, and `x86_64`.

## Завантаження для Android

[Завантажити останній універсальний APK](https://github.com/smmlt/hit-tracker-mobile/releases/latest/download/HitTracker-Android-universal.apk) для Android 7.0 або новішої версії. APK містить `armeabi-v7a`, `arm64-v8a`, `x86` та `x86_64`.

## Local development / Локальна розробка

```powershell
npm install
npm run start
```
